# Генератор паролей

Клиентское веб-приложение на React + Vite для быстрого создания случайных паролей прямо в браузере. Ничего не отправляется на сервер: длина, символы и итоговая строка обрабатываются только на вашем устройстве.

**Возможности:**

- длина пароля от 8 до 128 символов;
- наборы символов: латиница (A–Z, a–z), цифры, «безопасные» спецсимволы (без кавычек, слэшей, пробелов и символов, которые часто не принимают формы);
- генерация через `crypto.getRandomValues` с гарантией хотя бы одного символа из каждого выбранного набора;
- автоматическое обновление пароля при изменении настроек (если комбинация параметров допустима);
- индикатор надёжности текущего пароля;
- копирование в буфер обмена с подсказкой об успехе или ошибке;
- светлая и тёмная тема (сохранение выбора после переключения).

Демо: [ars000.github.io/password-generator](https://ars000.github.io/password-generator/).

## Запуск

```bash
npm install
npm run dev
```

Откройте URL из вывода команды (обычно http://localhost:5173).

## Сборка

```bash
npm run build
npm run preview
```

Сборка для GitHub Pages (относительные пути `./` для корректной загрузки JS/CSS):

```bash
npm run build:pages
```
